# پرس‌یار (PorsYar) 📋✨

فرم‌ساز و نظرسنجی آنلاین فارسی — مشابه پرس‌لاین — با دیزاین‌سیستم «استیکر-کولاژ» رکاد.

ساخته‌شده با **React 18 + Vite + Tailwind CSS + Supabase** و آماده‌ی دیپلوی روی **Vercel**.

---

## امکانات v1

### صفحه‌ی عمومی پر کردن فرم (`/f/:slug`)
- ✅ سوال‌ها **یکی‌یکی** با انیمیشن اسلاید و نوار پیشرفت
- ✅ **پیام ورود** (خوش‌آمد) و **پیام خروج** — کاملاً قابل تنظیم
- ✅ ۸ نوع سوال:
  | نوع | توضیح |
  |---|---|
  | متن کوتاه | یک‌خطی |
  | متن بلند | پاراگراف |
  | شماره موبایل ایران | `09xxxxxxxxx` ، `+98...` و ارقام فارسی همه قبول و نرمال می‌شوند |
  | چندگزینه‌ای | ۲ تا ۶ گزینه (پیش‌فرض ۴ گزینه) — با انتخاب، خودکار مرحله بعد |
  | ایمیل | با اعتبارسنجی فرمت |
  | عدد | فقط عدد |
  | ستاره امتیاز | ۱ تا ۵ |
  | بله/خیر | دو دکمه بزرگ |
- ✅ سوال اجباری/اختیاری، کلید Enter برای رفتن به بعد
- ✅ **پیش‌نویس خودکار**: اگر وسط فرم صفحه رفرش شود، جواب‌ها از `localStorage` برمی‌گردد (۷ روز اعتبار)
- ✅ تله‌ی ربات (honeypot)
- ✅ ثبت کامل متادیتا برای هر پاسخ (ببینید همه‌چیز را!)

### پنل ادمین (`/admin`)
- 🔐 لاگین با Supabase Auth (ایمیل/رمز)
- 📊 **داشبورد**: تعداد فرم‌ها، کل پاسخ‌ها، پاسخ‌های کامل، میانگین زمان + جدول آخرین پاسخ‌ها
- 🗂️ **مدیریت فرم‌ها**: ساخت، ویرایش، کپی، حذف، انتشار/لغو انتشار، کپی لینک
- 🧩 **فرم‌ساز**: عنوان/توضیح/اسلاگ، پیام ورود و خروج، افزودن/حذف/جابجایی سوال‌ها، ویرایش گزینه‌ها
- 📋 **پاسخ‌ها**:
  - جدول همه‌ی پاسخ‌ها: **ساعت پاسخ**، مدت، وضعیت، دستگاه
  - جزئیات هر پاسخ: جواب تک‌تک سوال‌ها + **زمان صرف‌شده روی هر سوال** + ساعت شروع/ثبت + دستگاه/مرورگر/سیستم‌عامل + منبع ورود
  - **تحلیل سوال‌ها**: درصد و نمودار میله‌ای گزینه‌ها، فهرست جواب‌های متنی
  - **خروجی CSV** (سازگار با اکسل فارسی — UTF-8 BOM)
  - 🟢 **ریل‌تایم**: هر پاسخ جدید لحظه‌ای با توست و بروزرسانی خودکار می‌آید (Supabase Realtime)

### امنیت (RLS)
- فرم منتشرنشده برای عموم قابل دیدن نیست
- ثبت پاسخ فقط برای فرم‌های منتشرشده ممکن است
- خواندن/تغییر همه‌ی داده‌ها فقط با لاگین ادمین

## 🚀 راه‌اندازی قدم‌به‌قدم

### قدم ۱ — ساخت پروژه Supabase (۵ دقیقه، رایگان)
1. برو به [supabase.com](https://supabase.com) → **New Project**
2. نام دلخواه (مثلاً `porsyar`) و یک رمز دیتابیس بده و منتظر بمان پروژه ساخته شود.
3. در داشبورد پروژه → **SQL Editor** → **New query**
4. کل محتوای فایل `supabase/migrations/0001_init.sql` را کپی‌کن، **Paste** و **Run** کن.
   - پیام `Success. No rows returned` یعنی همه‌چیز درست است.

### قدم ۲ — ساخت یوزر ادمین تستی
1. در داشبورد Supabase → **Authentication** → **Users** → **Add user** → *Create new user*
2. مثلاً:
   - Email: `admin@porsyar.ir`
   - Password: `Porsyar@1404`
   - تیک **Auto Confirm User** بزن.
3. **Create user** — تمام! (پروفایل به‌صورت خودکار توسط تریگر ساخته می‌شود.)

> این همان یوزر تستی ادمین است؛ با آن در `/admin/login` وارد شو.

### قدم ۳ — اجرای محلی
```bash
cd Desktop/porsyar
npm install
cp .env.example .env   # در ویندوز: copy .env.example .env
```
سپس فایل `.env` را بازکن و مقادیر را از **Project Settings → API** در Supabase بردار:
```
VITE_SUPABASE_URL=https://xxxx.supabase.co
VITE_SUPABASE_ANON_KEY=eyJhbGciOi...
```
و اجرا:
```bash
npm run dev
```
- سایت: `http://localhost:5173`
- پنل ادمین: `http://localhost:5173/admin`

### قدم ۴ — دیپلوی روی Vercel
1. پوشه‌ی پروژه را روی GitHub **push** کن (یا در Vercel مسیر محلی را import کن).
2. در [vercel.com](https://vercel.com) → **Add New → Project** → ریپو را انتخاب کن.
3. (Framework به‌صورت خودکار Vite تشخیص داده می‌شود.)
4. در بخش **Environment Variables** دو متغیر اضافه کن:
   - `VITE_SUPABASE_URL`
   - `VITE_SUPABASE_ANON_KEY`
5. **Deploy** — تمام! 🎉

> هر بار که کلیدها را در Vercel عوض کردی باید **Redeploy** بزنی.

## نکته‌ها
- **Realtime**: اگر پاسخ‌های زنده نیامدند، در Supabase → **Database → Replication** مطمئن شو `supabase_realtime` فعال است (migration خودش فعال می‌کند).
- **اسلاگ فرم**: فقط حروف انگلیسی کوچک، عدد و `-` (بین ۳ تا ۶۴ کاراکتر). لینک نهایی: `/f/اسلاگ`
- **حذف فرم** = حذف سوال‌ها و همه‌ی پاسخ‌هایش (cascade).
- ورژن v1 **تک‌ادمین** است: هر کاربری که در Authentication ساخته شود ادمین است؛ برای کاربر عادی نساز!
