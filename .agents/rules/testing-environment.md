# خط‌مشی اکید: ممنوعیت کامل تست روی سرورهای لایو و پروداکشن

## قانون الزامی و همیشگی:
1. **ممنوعیت کامل تست روی لایو:** به هیچ عنوان و تحت هیچ شرایطی نباید هیچ‌گونه تست واقعی، ارسال ریکوئست، ثبت رکورد یا فراخوانی API روی سایت و پروژه‌های ران‌شده روی سرور اصلی یا لایو (مانند `https://porskad.vercel.app` و دامنه‌های واقعی) اجرا شود؛ زیرا کاربران واقعی در حال استفاده از سامانه هستند.
2. **انحصار تست‌ها به لوکال هاست:** کلیه تست‌ها، بررسی‌های عملکردی و اعتبارسنجی‌ها منحصراً باید روی **لوکال هاست (`localhost`)**، اسکریپت‌های ایزوله محلی یا تست‌های آفلاین انجام گیرند.
3. **اعتبارسنجی آفلاین:** بیلد پروژه و آزمون‌ها باید به صورت آفلاین با `npm run build` و شبیه‌سازهای داخلی بدون ارسال ترافیک یا بار اضافی به سیستم لایو انجام شود.
